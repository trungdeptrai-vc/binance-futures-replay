# REPLAY

Terminal replay nến USDT-M perpetual futures của Binance.

- Bar replay: phát, dừng, bước nến, tốc độ, điểm bắt đầu ngẫu nhiên
- Khung 15m, 1H, 4H, 1D, 1W
- EMA 34 / EMA 89
- Trendline, nam châm giá
- Dữ liệu kho công khai Binance Futures (`data.binance.vision`), gộp nến live khi gọi được

```bash
npm install
npm run dev
```
